# Ada Implementation

Ada with `Unbounded_String` and `Replace_Element` for the carry.

One of 42 implementations of the same console protocol in the
[Turing Machines](../../README.md) repository: every implementation reads
the same stdin and prints **byte-for-byte identical output**, so a single
master test verifies them all at once.

* **Category:** Systems
* **Source:** [`langs/Ada/TuringMachine.ada`](TuringMachine.ada)
* **File-extension tag:** `.ada`
* **Showcase route:** [https://turing.pattygcoding.com/ada](https://turing.pattygcoding.com/ada)

## Prerequisites

* **Toolchain:** GNAT (Ada 2012), via Alire or MSYS2
* **Check it is installed:** `gnatmake --version`

| Platform | Install command |
| --- | --- |
| Windows | `alr toolchain --select gnat_native` |
| macOS | `brew install gnat` |
| Debian/Ubuntu | `apt-get install gnat` |

## How to run

From the repository root, build this implementation and replay every
scenario:

```sh
python tests/run_tests.py --only ada
```

Build and run it on its own:

```sh
mkdir -p tests/build/ada
cp langs/Ada/TuringMachine.ada tests/build/ada/turingmachine.adb
gnatmake -O2 -D tests/build/ada -o tests/build/turing_machine_ada tests/build/ada/turingmachine.adb
./tests/build/turing_machine_ada
```

## Protocol

[`README.md`](../../README.md#the-machine-and-the-console-protocol)
documents the machine and the exact output, and
[`tests/run_tests.py`](../../tests/run_tests.py) holds the build and run
commands the suite uses for every language.
[`tests/expected/`](../../tests/expected) is the authoritative golden output.

The nine scenarios cover a plain increment (`1011`), `0`, `1`, a full carry
chain (`1111` -> `10000`), a leading zero (`00101` -> `00110`), an empty
tape, a long tape (`0101010101` -> `0101010110`), rejected invalid input and
end of input.

## Notes

* GNAT only accepts `.adb`/`.ads` source files, so the runner copies the repository file (which keeps the Ada 83 `.ada` extension) to `tests/build/ada/turingmachine.adb` before building.
* `Get_Line` raises `End_Error` at end of input, which is caught and treated as an empty tape.
