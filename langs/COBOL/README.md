# COBOL Implementation

GnuCOBOL with a padded tape record and reference modification.

One of 42 implementations of the same console protocol in the
[Turing Machines](../../README.md) repository: every implementation reads
the same stdin and prints **byte-for-byte identical output**, so a single
master test verifies them all at once.

* **Category:** Legacy
* **Source:** [`langs/COBOL/TuringMachine.cob`](TuringMachine.cob)
* **File-extension tag:** `.cob`
* **Showcase route:** [https://turing.pattygcoding.com/cobol](https://turing.pattygcoding.com/cobol)

## Prerequisites

* **Toolchain:** GnuCOBOL 3 (`cobc`)
* **Check it is installed:** `cobc --version`

| Platform | Install command |
| --- | --- |
| Windows | `choco install gnucobol` |
| macOS | `brew install gnu-cobol` |
| Debian/Ubuntu | `apt-get install gnucobol` |

## How to run

From the repository root, build this implementation and replay every
scenario:

```sh
python tests/run_tests.py --only cobol
```

Build and run it on its own:

```sh
cobc -x -free -o tests/build/turing_machine_cobol langs/COBOL/TuringMachine.cob
./tests/build/turing_machine_cobol
```

## Protocol

[`README.md`](../../README.md#the-machine-and-the-console-protocol)
documents the machine and the exact output, and
[`tests/run_tests.py`](../../tests/run_tests.py) holds the build and run
commands the suite uses for every language.
[`tests/expected/`](../../tests/expected) is the authoritative golden output.

The nine scenarios cover a plain increment (`1011`), `0`, `1`, a full carry
chain (`1111` -> `10000`), a leading zero (`00101` -> `00110`), an empty
tape, a long tape (`0101010101` -> `0101010110`), rejected invalid input and
end of input.

## Notes

* `ACCEPT` reads the line, trailing spaces and carriage returns are trimmed, and the carry is applied to a `PIC X(258)` tape with reference modification.
* On Windows the runner points `COB_CONFIG_DIR` at GnuCOBOL's own tool directory, otherwise `cobc` looks for its config beside the Chocolatey shim.
