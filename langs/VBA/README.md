# VBA Implementation

VBA with `Mid`/`Left` string surgery, reading `input.txt`.

One of 42 implementations of the same console protocol in the
[Turing Machines](../../README.md) repository: every implementation reads
the same stdin and prints **byte-for-byte identical output**, so a single
master test verifies them all at once.

* **Category:** Legacy
* **Source:** [`langs/VBA/TuringMachine.vba`](TuringMachine.vba)
* **File-extension tag:** `.vba`
* **Showcase route:** [https://turing.pattygcoding.com/vba](https://turing.pattygcoding.com/vba)

## Prerequisites

* **Toolchain:** Microsoft Office (the VBA editor)
* **Check it is installed:** `Alt+F11 in Excel/Word`

| Platform | Install command |
| --- | --- |
| Windows | `install Microsoft Office` |
| macOS | `install Microsoft Office` |
| Debian/Ubuntu | `not available (Office is Windows/macOS only)` |

## How to run

From the repository root, build this implementation and replay every
scenario:

```sh
python tests/run_tests.py --only vba
```

Build and run it on its own:

There is no console entry point for VBA. Import `TuringMachine.vba` into a
module, put the tape in `input.txt` beside the workbook, run `TuringMachine`,
then open the Immediate window (`Ctrl+G`) to read the two result lines.

## Protocol

[`README.md`](../../README.md#the-machine-and-the-console-protocol)
documents the machine and the exact output, and
[`tests/run_tests.py`](../../tests/run_tests.py) holds the build and run
commands the suite uses for every language.
[`tests/expected/`](../../tests/expected) is the authoritative golden output.

The nine scenarios cover a plain increment (`1011`), `0`, `1`, a full carry
chain (`1111` -> `10000`), a leading zero (`00101` -> `00110`), an empty
tape, a long tape (`0101010101` -> `0101010110`), rejected invalid input and
end of input.

## Notes

* VBA has no console stdin, so the tape is read from `input.txt` beside the workbook and the two result lines go to the Immediate window with `Debug.Print`.
* No VBA interpreter is available on the machine this repository was developed on, so the runner skips this implementation.
