# PHP Implementation

PHP 8 with a `str_split` array tape and `array_unshift`.

One of 42 implementations of the same console protocol in the
[Turing Machines](../../README.md) repository: every implementation reads
the same stdin and prints **byte-for-byte identical output**, so a single
master test verifies them all at once.

* **Category:** Web
* **Source:** [`langs/PHP/TuringMachine.php`](TuringMachine.php)
* **File-extension tag:** `.php`
* **Showcase route:** [https://turing.pattygcoding.com/php](https://turing.pattygcoding.com/php)

## Prerequisites

* **Toolchain:** PHP 8 or newer (CLI)
* **Check it is installed:** `php --version`

| Platform | Install command |
| --- | --- |
| Windows | `scoop install php` |
| macOS | `brew install php` |
| Debian/Ubuntu | `apt-get install php-cli` |

## How to run

From the repository root, build this implementation and replay every
scenario:

```sh
python tests/run_tests.py --only php
```

Build and run it on its own:

```sh
php langs/PHP/TuringMachine.php
```

## Protocol

[`README.md`](../../README.md#the-machine-and-the-console-protocol)
documents the machine and the exact output, and
[`tests/run_tests.py`](../../tests/run_tests.py) holds the build and run
commands the suite uses for every language.
[`tests/expected/`](../../tests/expected) is the authoritative golden output.

The nine scenarios cover a plain increment (`1011`), `0`, `1`, a full carry
chain (`1111` -> `10000`), a leading zero (`00101` -> `00110`), an empty
tape, a long tape (`0101010101` -> `0101010110`), rejected invalid input and
end of input.

## Notes

* `str_split('')` is special-cased to an empty array, because older PHP releases returned `['']`.
