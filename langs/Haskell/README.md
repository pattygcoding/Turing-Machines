# Haskell Implementation

Haskell with a pure `increment` written as a reverse-and-carry fold.

One of 42 implementations of the same console protocol in the
[Turing Machines](../../README.md) repository: every implementation reads
the same stdin and prints **byte-for-byte identical output**, so a single
master test verifies them all at once.

* **Category:** Functional
* **Source:** [`langs/Haskell/TuringMachine.hs`](TuringMachine.hs)
* **File-extension tag:** `.hs`
* **Showcase route:** [https://turing.pattygcoding.com/haskell](https://turing.pattygcoding.com/haskell)

## Prerequisites

* **Toolchain:** GHC 9 or newer
* **Check it is installed:** `ghc --version`

| Platform | Install command |
| --- | --- |
| Windows | `choco install ghc` |
| macOS | `brew install ghc` |
| Debian/Ubuntu | `apt-get install ghc` |

## How to run

From the repository root, build this implementation and replay every
scenario:

```sh
python tests/run_tests.py --only haskell
```

Build and run it on its own:

```sh
ghc -O2 -outputdir tests/build/haskell -o tests/build/turing_machine_haskell langs/Haskell/TuringMachine.hs
./tests/build/turing_machine_haskell
```

## Protocol

[`README.md`](../../README.md#the-machine-and-the-console-protocol)
documents the machine and the exact output, and
[`tests/run_tests.py`](../../tests/run_tests.py) holds the build and run
commands the suite uses for every language.
[`tests/expected/`](../../tests/expected) is the authoritative golden output.

The nine scenarios cover a plain increment (`1011`), `0`, `1`, a full carry
chain (`1111` -> `10000`), a leading zero (`00101` -> `00110`), an empty
tape, a long tape (`0101010101` -> `0101010110`), rejected invalid input and
end of input.

## Notes

* `getContents` reads all of stdin, so the first line is taken and any trailing carriage return stripped; the carry is a small recursive function over the reversed string.
