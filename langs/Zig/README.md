# Zig Implementation

Zig 0.16 with the new `std.Io` file API and a fixed tape buffer.

One of 42 implementations of the same console protocol in the
[Turing Machines](../../README.md) repository: every implementation reads
the same stdin and prints **byte-for-byte identical output**, so a single
master test verifies them all at once.

* **Category:** Systems
* **Source:** [`langs/Zig/TuringMachine.zig`](TuringMachine.zig)
* **File-extension tag:** `.zig`
* **Showcase route:** [https://turing.pattygcoding.com/zig](https://turing.pattygcoding.com/zig)

## Prerequisites

* **Toolchain:** Zig 0.16 or newer
* **Check it is installed:** `zig version`

| Platform | Install command |
| --- | --- |
| Windows | `choco install zig` |
| macOS | `brew install zig` |
| Debian/Ubuntu | `apt-get install zig` |

## How to run

From the repository root, build this implementation and replay every
scenario:

```sh
python tests/run_tests.py --only zig
```

Build and run it on its own:

```sh
zig build-exe -O ReleaseFast --name turing_machine_zig -femit-bin=tests/build/turing_machine_zig langs/Zig/TuringMachine.zig
./tests/build/turing_machine_zig
```

## Protocol

[`README.md`](../../README.md#the-machine-and-the-console-protocol)
documents the machine and the exact output, and
[`tests/run_tests.py`](../../tests/run_tests.py) holds the build and run
commands the suite uses for every language.
[`tests/expected/`](../../tests/expected) is the authoritative golden output.

The nine scenarios cover a plain increment (`1011`), `0`, `1`, a full carry
chain (`1111` -> `10000`), a leading zero (`00101` -> `00110`), an empty
tape, a long tape (`0101010101` -> `0101010110`), rejected invalid input and
end of input.

## Notes

* The stdin read uses `std.Io.File.stdin().readStreaming(...)` and output uses `writeStreamingAll`, both through a `std.Io.Threaded` instance - the API introduced in Zig 0.16.
* The tape and the output buffer are fixed-size arrays, so no allocator is needed for the simulation.
