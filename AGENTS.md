# AGENTS.md

Guidance for AI coding agents adding languages to this repository.

## Golden rule

Every implementation must produce **byte-for-byte identical stdout** for the same
stdin. `tests/expected/` holds the authoritative golden output; `tests/run_tests.py`
builds every language, replays every scenario and checks that they all agree.

## The machine

The canonical machine is a **binary incrementer**, documented in `README.md`:

* read one line from stdin (only `0` and `1`; empty is allowed),
* in state `q0` a `1` becomes `0` and the head moves left (carry); the first `0`
  becomes `1` and the machine halts; a blank becomes a new leading `1` and the
  machine halts,
* print `Initial tape: <input>` then `Final tape: <result>`.

Invalid input prints exactly `Invalid input: expected a binary string.`

## File style

* **No top-of-file banner comments in implementation files.** Keep comments inline
  beside the code they explain, and put build/run instructions in the generated
  `langs/<Language>/README.md` and `tests/run_tests.py`, not in the source. Every
  folder's README.md is generated by `tools/generate_language_readmes.py` - never
  hand-edit one.
* `docs/links.md` is generated too (`tools/generate_link_index.py`): it lists every
  address the site answers, so add a link there by regenerating, never by editing
  the file by hand.
* **Indent with 4 spaces per level.** Never tabs, even in languages whose usual
  convention differs (Go, JavaScript, ...).
* Read exactly one line of stdin and never print anything else: no prompts, no
  step logs, no trailing banners.

## Workflow when adding a language

1. Pick a language and confirm its toolchain is installed. If it is missing,
   install it instead of asking.
2. Create `langs/<Language>/TuringMachine.<ext>` implementing the protocol exactly.
3. Register it in `LANGUAGES` in `tests/run_tests.py`:
   * `name`    - short id, matching the showcase id in `generate_dashboard.py`
   * `source`  - path to the source file
   * `build`   - argv (or a list of argv steps) that compiles it, or `None`
   * `artifact`- built output path under `tests/build/` (git-ignored)
   * `run`     - argv that runs it
4. Run `python tests/run_tests.py --only <name>` until every scenario passes.
   Fix the implementation, never the goldens.
5. Add the language to `LANGUAGE_INFO` in `tools/generate_dashboard.py`
   (display name, Prism class, category, extension) and run `npm run data`.
6. Add a `LANGUAGE_FACTS` entry (tagline, toolchain, detect, install commands,
   notes) to `tools/generate_language_readmes.py`, then run `npm run readmes` to
   write `langs/<Language>/README.md` and `npm run links` to refresh
   `docs/links.md`.
7. Update the language count in `README.md` if the total changes.

## What stays untracked

`.gitignore` is the source of truth: `tests/build/`, `dist/`,
`public/dashboard-data.js`, `node_modules/`, `__pycache__/` and editor cruft.
Never commit a compiled program, a capture, or a build output.
